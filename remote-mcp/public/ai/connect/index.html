Connect the tools

Availability and labels depend on your account and workspace policy. This is a custom connection; a ChatGPT or Claude directory listing is not claimed.

ChatGPT

  1. If Developer mode is available for your account, enable it under Settings → Security and login.
  2. Open ChatGPT Plugins, select “+” and name the connection VNISH Global Operator.
  3. Under Connection, enter the server URL above. This public server needs no OAuth sign-in or API key.
  4. Review the three discovered tools and add the connection to a new conversation.

OpenAI connection guide

Claude

  1. Open Customize → Connectors.
  2. Select “+”, then Add custom connector.
  3. Enter VNISH Global Operator and the server URL above. Leave OAuth fields empty.
  4. Enable the connection through the chat’s Connectors menu. A workspace owner may need to add it first.

The second example returns $1.099 per day after the modeled fee and electricity. This checks the arithmetic under the supplied assumptions.

Sources and scope

A catalog record does not confirm compatibility with a particular device or successful installation. The tool does not verify a downloaded archive or connect to a miner. Identify an unknown model or control board first.

The example’s 2% is an illustrative assumption, not a published VNISH fee. The calculation fetches no market data and excludes hardware cost, cooling, taxes and other expenses. Its result is not net profit or a payback forecast.

Selected identifiers and scenario numbers are sent to vnish.global. The server code does not store tool arguments. Standard hosting logs may contain request metadata. These tools need no passwords, miner IP address, configuration files or account data.
